## Layouts diverge by operand (v6 lesson)

- A: 64-row QUADRANT layout per wg — atoms (r/8)*128 + chunk*1024,
  descriptor LBO=1024 (same as v2-v5).
- B: FULL 128-row layout — atoms (r/8)*128 + chunk*2048, descriptor
  LBO=2048. Reason: m64n128 walks 16 n-atoms at SBO=128 = 2048B span per
  k-chunk; reusing the 64-row quadrant layout made the hardware read
  k-chunk-1 bytes as n-atoms 8..15 (verify FAIL 0.17 while running fast).
- Rule: the SMEM layout of an operand is determined by the MACRO SHAPE's
  traversal (M-atoms for A, N-atoms for B), not by tile geometry alone.
