🔥 GPU Kernel Programming — Zero to Expert

A structured 22-chapter curriculum · CUDA → ROCm → Triton → JAX · ending at DSA sparse MLA

How to use this tutorial: Read chapters in order. Every page has real code — type it out, don't copy-paste. The GEMM optimization ladder (chapters 06-12) is the heart of the curriculum: each step solves a bottleneck from the previous one. By chapter 20, you'll understand the path to writing a DSA sparse MLA decode kernel from scratch.

🎯 Learning Philosophy

  1. Problem before solution. Before each optimization, explain what bottleneck the previous step has — with concrete numbers (GB/s, TFLOPS, latency).
  2. Always show code. Every concept comes with a real kernel. No abstract tables without code.
  3. Start from absolute basics. Don't assume knowledge of threadIdx, blockIdx, or memory hierarchy. No concept is too basic.
  4. Confirm at each step. After each concept, stop. Don't proceed until understanding is confirmed.
  5. Build to DSA. Everything points toward the end goal: writing a DSA sparse MLA decode kernel.

🗺️ Prerequisites

You need a machine with an NVIDIA GPU (for CUDA chapters) or AMD GPU (for ROCm chapters), plus the respective toolkit. For Triton, any GPU works. The easiest setup:

# CUDA (NVIDIA)
sudo apt install nvidia-cuda-toolkit
nvcc --version

# ROCm (AMD)
sudo apt install rocm-dev
hipcc --version

# Triton (any GPU)
pip install triton

# Practice environment — use a GPU pod/container
# c.ai: amd4 dev pod for MI350X, pi1 for H100
