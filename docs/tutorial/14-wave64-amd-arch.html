1. Wavefront = 64 (not 32)

On NVIDIA, the warp size is 32. On AMD, the wavefront size is 64. This is the most important architectural difference — it affects how you write efficient kernels.

NVIDIA (warp)AMD (wavefront)
Size32 threads64 threads
Lockstep executionYesYes
Divergence cost2-way = 50% idle2-way = 50% idle (but 64 threads wasted)
Shuffle (__shfl)Within 32 threadsWithin 64 threads (__shfl with wave size 64)
Block size matters! On AMD, blockDim.x should be a multiple of 64 for efficiency. A block of 256 threads = 4 wavefronts (good). A block of 48 threads = 1 wavefront with 16 idle lanes (bad — 25% waste).

3. What wave64 changes in practice

// NVIDIA: warp reduction with 5 steps (log2(32))
for (int offset = 16; offset > 0; offset /= 2)
    val += __shfl_down_sync(0xffffffff, val, offset);

// AMD: wavefront reduction with 6 steps (log2(64))
for (int offset = 32; offset > 0; offset /= 2)
    val += __shfl_down(val, offset);  // no mask needed on AMD

4. VGPR and SGPR registers

AMD has two types of registers:

  • VGPR (Vector General Purpose Register) — per-thread, like CUDA registers
  • SGPR (Scalar General Purpose Register) — per-wavefront, shared across all 64 threads. Used for values that are the same for all threads (e.g., loop bounds, base pointers).
SGPR is unique to AMD. NVIDIA doesn't have a scalar register file — everything is per-thread. AMD's SGPR can save registers when values are uniform across the wavefront. The compiler handles this automatically, but you can help by making uniform values const or passing as kernel arguments.

🎯 Chapter 14 Summary

AMD's wavefront = 64 (vs NVIDIA's warp = 32). Block size should be a multiple of 64. CU (Compute Unit) ≈ SM, Matrix Core ≈ Tensor Core, LDS ≈ Shared Memory. MI300X has 192GB HBM and 5.3 TB/s bandwidth (more than H100). AMD has VGPR (per-thread) and SGPR (per-wavefront scalar) registers — SGPR saves registers for uniform values.

🧪 Quick Check

Your CUDA kernel uses blockDim.x = 48. What happens on AMD?

A wavefront is 64 threads. 48 threads = 1 wavefront with 16 idle lanes (25% waste). The wavefront still executes 64-wide, but 16 lanes are masked off. Fix: use blockDim.x = 64 (1 full wavefront) or 128 (2 wavefronts). Always make block dimensions multiples of 64 on AMD.
