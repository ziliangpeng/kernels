1. What is Pallas?

Pallas is JAX's custom kernel DSL. It lets you write GPU kernels in Python with the same mental model as Triton (block-level programming), but with the added benefit of JAX's autodiff, JIT compilation, and XLA integration. Pallas kernels can be differentiated — you can backprop through them.

TritonPallas
FrameworkStandaloneJAX
AutodiffNo (manual backward)Yes (automatic)
BackendsNVIDIA, AMDTriton (NVIDIA/AMD), TPU
Block abstractiontl.arangejax.lax + grid
Use caseProduction kernelsResearch + TPU + autodiff

2. First Pallas kernel

import jax
import jax.numpy as jnp
from jax.experimental import pallas as pl

def vector_add(x, y):
    def kernel(x_ref, y_ref, z_ref):
        # x_ref, y_ref are block references — like Triton pointers
        z_ref[:] = x_ref[:] + y_ref[:]

    return pl.pallas_call(
        kernel,
        out_shape=jax.ShapeDtypeStruct(x.shape, x.dtype),
        grid=(x.shape[0] // 1024,),
        in_specs=[
            pl.BlockSpec((1024,), lambda i: (i * 1024,)),
            pl.BlockSpec((1024,), lambda i: (i * 1024,)),
        ],
        out_specs=pl.BlockSpec((1024,), lambda i: (i * 1024,)),
    )(x, y)

3. Lowering to Triton

Pallas with the Triton backend lowers to Triton, which then compiles to GPU code. This means Pallas kernels get the same tensor core auto-emit and autotuning as Triton.

# Pallas → Triton → PTX/GCN
# The lowering is automatic:
#   pl.BlockSpec → tl.arange + tl.load/store
#   jnp operations → tl operations
#   grid → program_id loop

4. When to use Pallas vs Triton

Use Triton for production kernels (FlashAttention, vLLM, SGLang). It's mature, well-documented, and has the largest ecosystem. Use Pallas when you need: (1) autodiff through a custom kernel, (2) TPU support, (3) integration with JAX/XLA pipelines, (4) rapid prototyping with JAX's debugging tools.

🧪 Quick Check

When would you choose Pallas over Triton?

When you need autodiff through a custom kernel (Triton requires manual backward), TPU support (Triton only does GPU), or JAX/XLA pipeline integration (Pallas compiles within JAX's jit/grad/vmap). For pure production GPU kernels (FlashAttention, vLLM), Triton is more mature and has a larger ecosystem.
